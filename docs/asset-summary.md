# M1-05：現金與銀行資產摘要

首頁從同一工作階段已重建的 Ledger 帳戶餘額計算摘要；這是唯讀結果，沒有第二份持久餘額或投影。此批對應 [RC-13](architecture-baseline-v1.0-rc1.md#rc-13) 基本資產讀取子集，較完整的資產與估值願景見 [FV-049](full-vision-baseline.md#fv-049)。

- 只納入目前支援的現金與銀行帳戶，尊重帳戶的 `includeInNetWorth` 設定。封存但仍有餘額的帳戶不因無法新入帳而消失；被明確排除的帳戶另顯示數量。
- 每個幣別分開合計，允許負餘額。期初餘額與轉帳本金已在各帳戶餘額中，轉帳只是帳戶間移動；跨幣轉帳保存實際兩端本金，不能直接換算成單一總額。
- 畫面使用「資產摘要」標題，但明示目前只有現金／銀行餘額，**沒有跨幣估值、投資資產或完整淨資產**。每個幣別合計可核對首頁個別帳戶；隱私遮罩與背景鎖定同樣適用。
- 同一帳戶重複輸入或任一幣別合計超出 Money 範圍時，整份摘要拒絕顯示；不截斷、不顯示部分總額。個別帳戶資料保持原狀。

[商家維度](merchant-reports.md)另依歷史交易參照計算；帳戶維度與完整 M1-05 gate 仍待後續，投資估值在 M3。此摘要不提高當前開發版的正式資料保護或發版狀態。
