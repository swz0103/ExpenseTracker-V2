# 鎖定狀態的加密安全副本匯出

M1-07 的部分安全模式能力。當 V2 設定檔無法讀取或帳本不能解鎖，而本機仍保有先前「確認還原」或「備份並更新」產生的加密副本時，鎖定／阻擋畫面提供兩個分別命名的唯讀匯出入口。使用者須輸入該副本的原帳本密碼或救援文字；App 解密並驗證快照後，才交給 Android 文件儲存流程。匯出的是原加密封套，不會重設密碼、解鎖目前帳本、替換資料或刪除既有檔案。

若有多份還原前副本，選最後修改時間最新的一份；同時間以檔案路徑決定固定順序。驗證失敗、檔案過大或副本不存在時拒絕輸出，保留目前資料。匯出後可在獨立 V2 安裝中使用原憑證驗證還原。

升級前副本保存在 `upgrade-backups/`。升級可能中斷並留下未寫完的最新檔案，因此從最後修改時間最新者開始，逐一嘗試原憑證與該副本**原始 schema** 的完整快照驗證，匯出最近一份可驗證的封套。認證失敗、毀損、過大、未知或未來 schema 不會被輸出；若沒有可驗證副本就拒絕。畫面明示可能是較早的版本，還原後仍須經正式資料升級流程，不能直接將檔案當成目前資料庫覆蓋。

副本不存在、憑證遺失、所有檔案毀損或 Android 文件供應者不可用時，本功能無法恢復資料。完整 App PIN、實機文件儲存／回讀及其他安全模式路徑仍需後續驗證；本機測試不代表 M1-07 或雲端 gate 完成。
