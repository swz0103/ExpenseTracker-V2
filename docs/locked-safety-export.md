# 鎖定狀態的還原前安全副本匯出

M1-07 的部分安全模式能力。當 V2 設定檔無法讀取或帳本不能解鎖，而本機仍保有先前「確認還原」產生的加密安全副本時，鎖定／阻擋畫面提供唯讀匯出。使用者須輸入該副本的原帳本密碼或救援文字；App 解密並驗證快照後，才交給 Android 文件儲存流程。匯出的是原加密封套，不會重設密碼、解鎖目前帳本、替換資料或刪除既有檔案。

若有多份還原前副本，選最後修改時間最新的一份；同時間以檔案路徑決定固定順序。驗證失敗、檔案過大或副本不存在時拒絕輸出，保留目前資料。匯出後可在獨立 V2 安裝中使用原憑證驗證還原。

此入口只涵蓋「還原前」副本；升級前備份另存於 `upgrade-backups/`，目前沒有相同的鎖定狀態匯出入口。副本不存在、金鑰遺失、檔案毀損或 Android 文件供應者不可用時，本功能無法恢復資料。完整 App PIN、安全模式及實機文件儲存／回讀仍需後續驗證；本機測試不代表 M1-07 或雲端 gate 完成。
