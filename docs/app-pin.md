# V2 裝置專用 App PIN

App PIN 是使用者另外設定的 6–12 位數字，只保存在這台裝置，不寫入帳本、加密備份或同步資料。它與帳本密碼、備份救援文字分開。首批實作把 App PIN 作為**本機裝置解鎖的第二道檢查**：每次先通過 Android Keystore 的系統認證，再檢查 App PIN，兩者均通過才以受保護的帳本密碼副本開啟帳本。短 PIN 單獨不能解密資料；裝置不支援系統認證時，仍須使用帳本密碼。

使用者先以帳本密碼開啟帳本並明確啟用裝置解鎖，才能另行設定 App PIN。啟用與停用 PIN 均要求系統認證；停用 PIN 還需輸入目前 PIN。PIN 只存隨機鹽與衍生驗證值，五次錯誤後鎖住此捷徑。忘記 PIN、驗證資料無法讀取或裝置認證不可用時，帳本密碼仍可開啟；登入後可停用本機裝置解鎖並清除 PIN。停用裝置解鎖時，也一併清除 PIN。背景切換會鎖定畫面與帳本，不能接受過時的裝置認證或 PIN 驗證結果。

這是裝置本機登入捷徑，不是可攜的備份解鎖方式，也不取代密碼與救援文字兩條乾淨還原路徑。系統認證、Keystore 實際行為、裝置憑證變更和重裝後的狀態仍需 Android 實機驗收；主機測試及建置不能代替該 gate。M1-07 其他安全模式、隱私及雲端 gate 仍獨立保留。
