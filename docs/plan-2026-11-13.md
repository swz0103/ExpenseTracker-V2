## 一、這次已處理：畫面重疊與間距（0.9.2）

### 問題與根因

真機上看到的「有的疊在一起、有的分很開」，在 360 dp 寬、字級 130% 就能重現。我先前只用 390 dp、字級 100% 截圖對照，150% 的檢查也開在 400 dp 寬，所以沒抓到。根因有三：

1. **固定尺寸**：圓環固定 120、拼貼的小塊、主卡左右兩欄硬並排，都沒有跟著螢幕寬度與字級調整。
2. **用縮小代替換行**：用 `FittedBox` 把放不下的字縮小，小螢幕上縮到讀不到；有的直接溢位。
3. **間距各寫各的**：每一段自己加 `SizedBox`、`Padding`，`SectionHead` 自己又有上下間距，同一頁裡有 0、10、12、16、20 好幾種距離。

### 這次的修正

- 報表主卡：「收入」放不下時移到結餘下面。最下排、讀數列、比較的每一列放不下就換行。
- 分類拼貼：照字級算每塊的最小尺寸。先讓拼貼長高（最多 1.6 倍），真的放不下才把最小的分類併進「其他」。
- 常去商家：合計移到標題，圓環中間不再塞字。
- 「最常去」等色塊的店名太長就換行。
- 投資主卡：市值大字不再被「今日」膠囊擠小，膠囊放不下就換到下一行。
- 總覽和所有帶圓環的 `Tile`：窄的時候圓環移到數字上方。
- 新增 `Sections`／`section()`／`TitleRow`（`core/look/kit.dart`），一頁只有一種區塊間距與一種標題寫法。報表四個分頁已改用。

### 防止再發生

新的 `test/app/layout_test.dart` 每個 PR 都會跑：

- **範圍**：25 個頁面與分頁 × 寬度 320／360／412 dp × 字級 100／130／150%。
- **不能溢位**：任何 RenderFlex 溢位都算失敗。
- **文字不能重疊**：量的是實際畫出的字形範圍，經過所有縮放與裁切，只算最上層的頁面或面板。
- **不能縮太小**：字被縮到原本六成以下就算失敗。

這個檢查順帶抓到總覽、投資主卡這些先前就有的問題，也一起修了。

**還沒涵蓋的**：中間浮窗、底部面板、記一筆的各個子頁。這些放進下面的 Q2。

## 三、復盤

### 1. 程式碼

- **顏色重複**：同一組色號（報表 #5B8DB0、投資 #4A5D99…）在 `ToolHue`、`SettingsHue`、報表的 `_tabs`、投資分頁、標籤頁、預算頁各寫一次，改一個顏色要改五個檔。
  → 在 `theme.dart` 建一份 `Palette`（每個工具與每種設定一個具名 `Shade`），全部改用它，再加一個測試檢查 `lib/` 裡不能再出現裸色號。
- **主卡寫了六次**：`_Hero`（報表）、`_InvestHero`、預算 `_Main`、`_BothWays`、`ProjectCard`、`BackupHero` 都是「漸層＋小標＋大字＋細項」。
  → 抽成 `HeroCard`，並把這次的換行規則（放不下就換行、不縮小）做在裡面。
- **大分段按鈕寫了六次**：分類的支出／收入、標籤／商家、報表四分頁、投資兩分頁、定期交易表單、比較的切換。
  → 抽成 `BigSegments`（選中實色、未選淡色，含無障礙的 `selected`）。
- **單檔太大**：`reports.dart` 約 1,300 行、`recurring_page.dart` 約 1,000 行、`kit.dart` 約 800 行。
  → 報表每個分頁一個檔；定期交易分成月曆、日卡、子頁三個檔；kit 依元件拆檔，由 `widgets.dart` 匯出。
- **其他技術債**：
  - `PriceHistory` 需要強制轉型（`market as PriceHistory`）。改成 `Nav` 直接帶一個 `PriceHistory?`。
  - 圖示產生器 `tool/glyphs.py` 和 `glyphs.dart` 不同步（0.8.0 手加的帳戶圖示）。已另外建議一個工作。
  - 測試用文字找畫面（`find.text('本月還沒扣')`），文案一改就壞。關鍵畫面改用 `Key` 或 Semantics 標籤。
  - 截圖工具 `test/zz_shots` 目前只在我的環境。正式放進 `tool/`，CI 可選擇性輸出每頁淺色／深色截圖當 artifact，PR 審查時直接看圖。

### 2. 功能

- **自動入帳與垃圾桶一致性**：見上面 #1、#2、#5，這是目前最可能讓帳不對的地方，排第一。
- **0.9.0 還沒照定案完成的部分**（我先前沒列清楚）：
  - 投資·股息：「預計配息」要是每檔一段的疊色柱與平均虛線，現在仍是舊的逐月清單。
  - 每一檔：點買點要顯示「2024/3/12 買 60 股 @962 · 這批 +9.1%」；「已賣光」狀態；交易紀錄要改白色報價板。現在仍沿用舊的「持有批次」和紀錄列表。
  - 收支分頁：「收支與淨資產」要是紅柱、收入綠色小標、藍線疊在同一張；現在仍是舊的成對長條。
- **走勢圖**：
  - 減資、分割後的歷史價沒有還原，均價線會不對。在圖上標出股數變動的日子，均價改用「當時的」平均成本。
  - 沒有網路時只顯示文字，改用快取裡最後的資料，並標示「離線」。
- **分類拖曳排序**：螢幕閱讀器沒辦法操作。加上 Semantics 的「往前移／往後移」動作，另外提供不用拖曳的「排序模式」。
- **網頁預覽**：沒有偏好設定與通知服務，外觀、通知、安全幾頁在預覽裡看不到。給預覽一份記憶體版的服務。
- **Google 備份開關**：關掉時要一併提醒「背景的雲端硬碟上傳也停了」（目前會停，但畫面沒說）。另外加測試確認關掉後 `files/cloud/` 確實是空的。

### 3. UI／UX

- **標題位置不一致**：預算、報表、投資、更多是靠左的大標題，其他子頁是置中標題。定案稿本身也混用。建議統一成：tab 頁（更多、總覽…）靠左，子頁一律置中加返回。請你確認。
- **深色模式沒有自動檢查**：淡色卡上的深色字（`deepOf` 疊在 `tintOf` 上）沒有對比檢查。加測試：`Palette` 每個顏色在淺色、深色下 `deepOf(c)` 對 `tintOf(c)` 都要 ≥ 4.5:1。
- **空狀態不一致**：有的頁有大圖示加一句話，有的只有一行灰字（例如代墊沒有人時）。統一用 `EmptyState`，規則照定案。
- **其他**：
  - 中間浮窗裡的列表太長時（例如換日曆），在小螢幕會超出。浮窗設最大高度並可捲動，放進版面檢查。
  - 報表「收支與淨資產」的圖例在窄螢幕會擠到標題下一行，已經會換行。之後改用 `TitleRow` 的 trailing。
