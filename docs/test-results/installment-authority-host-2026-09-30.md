# M2-05 分期計畫權威保存主機紀錄（2026-09-30）

狀態：**資料層 opt-in，未接入正式 App**。本批沒有將分期資料放入加密備份或開放使用者畫面。

- `card_installment_plans` 以工作空間及購買事件為主鍵，操作 ID 唯一，外鍵指向 `card_posted_charges`。schema 20 只在顯式 `installmentsAware` 時建立，且要求 schema 19 的卡片授權資料層；既有 schema 18／19 路徑不變。
- 新建計畫核對已入帳卡片購買、卡片與幣別、本金加明列費用等於原購買金額、首期不早於入帳日期；拒絕已退款、更正、撤銷或軟刪除的購買。重複同一操作可回放，衝突操作與重複計畫拒絕。歷史計畫在後續退款後仍可讀取，不因新事件使備份驗證失敗。
- 寫入不新增 Ledger 消費、發卡行帳單或繳款分配。若實際額外費用不在原購買 Ledger 金額內，未來必須有獨立的同交易費用事實；目前不接受無來源的費用負債。
- 主機驗證：`packages/credit_cards` 14 項、`prototypes/modular_persistence` 前一來源全量 81 項全數通過；新增退款情境後定向 6 項通過，未重跑相同套件全量。兩套件靜態分析無問題。整合測試覆蓋正確保存、重試、錯金額、錯卡、未知購買、寫入回滾、計畫內容與 Ledger 購買金額竄改拒絕；後續退款保留史實，已退款購買不得新建計畫。快照入口尚未接入此驗證器，不能宣稱備份 gate 通過。
- 待補 gate：Ledger Session、加密快照與雙憑證還原、19→20 安全升級、App UI、實機與目前 SHA 的雲端檢查。當前 App 仍用 schema 18，不能宣稱分期可用或 M2-05 完成。
