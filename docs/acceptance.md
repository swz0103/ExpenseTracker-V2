# 實機驗收清單

> 在手機上要確認的事，依功能分；淺色、深色各看一次。全部打勾才升到 1.0.0。畫面或手機行為改變時更新這份，不按版本累積。

最近一次全部看過：尚未（0.10.1 起的項目都還沒在手機上走過）。

## 更新與資料

- [ ] 從上一版更新後，帳本照常打開，紀錄、帳戶、預算、定期交易都在。
- [ ] 0.19.0 起每版有自己的下載頁（`v<版號>`）：從 0.18.x 要手動裝一次 0.19.0，之後「設定 › 關於」與更新通知照常找到新版並下載。
- [ ] 設定 › 還原：上一版做的備份能還原。
- [ ] 有新版時打開 App 跳出更新通知；點旁邊、按返回不會關；「晚一點再說」當天不再跳，「略過這一版」之後只有更新的版本才跳。
- [ ] 帳本的資料庫不見時，解鎖會提示從備份還原，不會打開空帳本。

## 解鎖與安全

- [ ] 指紋或臉部解鎖：啟用、解鎖、取消後改用密碼；手機新增指紋後要用密碼解一次再重新啟用。
- [ ] 救援碼打開帳本；忘記密碼時改用救援碼。
- [ ] 背景一段時間後回到 App 會鎖定；最近任務畫面看不到帳本內容。

## 總覽

- [ ] 主卡：結餘下一條綠紅長條，收入、支出、其中股息寫在長條下；結餘率在數字右邊同一行，眼睛在右上角。
- [ ] 預算卡是「本月剩」加十格；即將扣款寫「N 天後」與下一筆；字都不換行。
- [ ] 每日紀錄：週曆從週日排到週六，選中那天是主色，下面那天的紀錄是一排可左右滑的小卡，點一張打開；桌面小工具的一週也從週日開始。

## 紀錄與記一筆

- [ ] 紀錄頁：主卡右上是「N 筆 · 轉帳 N」；左右滑頁面換月份，在一筆上左滑是編輯／刪除，填滿整列不露白。
- [ ] 點一筆只看到這筆的卡（有填的欄位才出現），按「編輯」才變表單。
- [ ] 記一筆：標題與金額固定在上方；打開再收起「商家、標籤、備註」或「拆分」，下面不留白；切到投資再切回支出不多空白。
- [ ] 收據：點方塊跳出「拍照」「從相簿」；拍歪的照片存下來是正的。
- [ ] 掃發票：第一次先下載掃描器，之後直接打開；沒有 Google Play 服務時說明原因。
- [ ] 刷卡分期 10,001 元分 3 期：寫「首期 3,335，其後每期 3,333」，信用卡頁第一期 3,335。
- [ ] 外幣帳戶記一筆：金額上方只寫一次幣別。
- [ ] 計算機：點金額欄任何地方都會打開；「完成」字級 17。

## 帳戶、信用卡、貸款

- [ ] 卡包：按住約半秒變成滾筒、輕震；上下拖時每經過一張輕震，放開停在最近一張，不會多轉；按「完成」整疊依順序排。
- [ ] 排序帳戶：按住 ≡ 立刻能拖，拿起時放大浮起；「手動／餘額／最近使用」一鍵排好，按完成才存。
- [ ] 新增帳戶：卡片上直接打名字、輸入餘額，點色點換顏色；選圖示是圓角方形，選中為實心。
- [ ] 新增貸款：每月繳與總利息即時顯示；貸款頁主卡多一行「本息平均 · 每月約 …」。
- [ ] 對帳：輸入實際餘額後提示差額，按「記下」後餘額相符。

## 投資

- [ ] 裝好幾小時後（背景抓過一次）打開投資，收盤價立刻是最新的。
- [ ] 持股分「個股」「ETF」；標的卡寫簡稱（台積電、台灣50），不是代號；股息頁選中的月份不超出黃底。
- [ ] 持股頁走勢圖：上市、上櫃都畫得出來；漲是紅、跌是綠（總覽的投資行情、投資頁、持股頁、賣出的已實現損益都一樣），收入支出仍是收入綠、支出紅。

## 預算、定期、報表

- [ ] 預算：沒設總預算時主卡只有「本月花了 …」與「設定預算」；選月份時每月寫用了幾成，超支紅、九成以上金色。
- [ ] 定期交易月曆：選中的那天外圍一圈同色框；好幾天沒開 App 後，到期的逐期補記。
- [ ] 報表：上方切換鈕、分類方塊點開看該分類的紀錄；比較寫「跟去年同期比」。

## 備份、提醒、匯入匯出

- [ ] 雲端硬碟：打勾就連結，顯示上次備份時間與「收據照片」開關；換手機後能還原。
- [ ] 存到資料夾：選擇器開在「文件」；選了不能用的位置會說明並可「重新選」；檔案直接在選的資料夾裡。
- [ ] 換手機：新手機的歡迎頁會問要不要從 Google 系統備份還原。
- [ ] 通知：每日提醒、到期提醒、預算提醒都會出現，點「已入帳」會記上；日曆同步寫入事件。
- [ ] 匯出 CSV 用試算表打開，不會執行公式。
- [ ] 桌面小工具：本月概況與快速記帳兩種都能放，數字跟著帳本更新。

## 深色、字級、動畫、讀屏

- [ ] 深色逐頁看：沒有比帳戶卡更亮的色塊；選中的按鈕是淡色底加外框；卡片沒有陰影。
- [ ] 手機字型調到最大：總覽的收入、支出各一行不斷開；投資的未實現、已實現、年化上下排；記一筆投資的股數、成交價在名稱下方。
- [ ] 開啟「移除動畫」：切分頁、展開「更多」、卡包都不動也不出錯；提示訊息仍停留幾秒。
- [ ] TalkBack：更多頁的每張卡、報表切換鈕、定期月曆的日子點兩下都會打開；分類圖示念出名稱；計算機刪除鍵念「刪除」。
- [ ] 震動：存檔輕一下、超支重一下；設定關掉震動後都不震。
