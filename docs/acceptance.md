# 實機驗收清單

每個版本合併、在手機上更新後逐項確認；淺色、深色各看一次。打勾後在 PR 或對話裡說一聲。

## 0.11.0　深色與質感

- [ ] 深色模式：總覽的圖表、分布條、分類色塊不比其他頁鮮豔刺眼；報表、標籤頁同樣柔和。
- [ ] 深色模式下選中的按鈕（報表分頁、投資持股／股息、標籤／商家、篩選類型、代墊與借貸、匯入匯出）是淡色底加同色外框與字，不是實心亮色塊；淺色模式不變。
- [ ] 卡片在深色下沒有陰影，以頁面底色、卡片、按鈕三階亮度分出層次。
- [ ] 震動回饋：記一筆讓預算超支時是較重的一下，平常存檔是輕的一下；拖曳帳戶排序、總覽區塊排序時每換一格輕震；切換開關時輕震。設定 › 外觀與操作 關掉「震動」後都不震。

## 0.10.1　快速修正

- [ ] 開關：設定各頁（通知與提醒、備份與還原、關於）與新增帳戶、總覽區塊，點開關所在那一列的任何地方都會切換；畫面上不再有原生的滑動開關。
- [ ] 帳戶頁淨資產主卡下方出現存款／投資／代墊／負債的分布長條。
- [ ] 總覽最下面不再有「調整總覽」（設定 › 外觀與操作 › 總覽區塊仍可調整）。
- [ ] 紀錄、帳戶、信用卡、報表的紀錄列往左滑，編輯／刪除填滿整列，上下與卡片邊緣都不露白（第一列與最後一列特別看）。
- [ ] 標籤或商家改名時鍵盤彈出，面板底部沒有多一大塊空白。
- [ ] 從商家頁返回，停在「商家」分頁。
- [ ] 預算的每月額度、定期交易的金額、貸款的原借金額與目前尚欠：點整個金額欄都會開計算機。
- [ ] 點一筆紀錄看詳情：備註只出現一次（沒有備註就不出現），沒有計算機圖示；轉帳紀錄沒有一大塊空白。
- [ ] 記一筆往下捲：標題與金額固定在上方，下面的欄位在交界處被裁切，捲動後出現一條細線。
- [ ] 記一筆的分類列與「拆分」之間的分隔線上下置中。
