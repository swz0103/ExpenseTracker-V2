## 0.18.0　架構整理、資料十年可讀、減少動態效果

- [ ] 從 0.17.0 更新後，帳本照常打開，紀錄、帳戶、預算、定期交易都在。
- [ ] 設定 › 還原：0.17.0 做的備份能還原。
- [ ] 新增帳戶：選圖示是圓角方形，選中為實心；卡片顏色每排 5 個、選中打勾；更多圖示裡每個圖示有名稱。
- [ ] 分類編輯：換圖示、顏色列與帳戶的樣式一樣。
- [ ] 記一筆 › 投資 › 全部標的：每張卡寫的是簡稱（台積電、台灣50、中信金），不是代號。
- [ ] 刷卡分期一筆 10,001 元分 3 期：記帳表單寫「首期 3,335，其後每期 3,333」；信用卡頁第一期顯示 3,335。
- [ ] 外幣帳戶記一筆：金額上方只寫一次 USD。
- [ ] 手機設定開啟「移除動畫」：切分頁、展開「更多」、卡包、總覽都不再有動畫，也不會出錯；關掉後恢復。
- [ ] 提示訊息（例如刪除後的「復原」）在移除動畫時仍停留幾秒。
- [ ] 開啟 TalkBack：更多頁的每張卡、財務報表上方的切換鈕、定期交易日曆的日子，點兩下都會打開。
- [ ] 開啟 TalkBack：分類 › 換圖示，每個圖示念出名稱（例如「圖示：咖啡」）；記一筆的計算機，刪除鍵念「刪除」。
- [ ] 手機字型大小調到最大：總覽的收入、支出各一行不斷開；投資的未實現、已實現、年化上下排；每週列的日期分得開；記一筆投資的股數、成交價寫在名稱下方。

## 0.17.0　背景收盤價、掃描器下載、卡包手感

- [ ] 更新：有新版時，打開 App 就跳出更新通知（「晚一點再說」當天不再跳）。
- [ ] 收盤價：裝好這版、過幾小時後（背景抓過一次）再打開投資，收盤價立刻是最新的，不用等「更新收盤價中」。
- [ ] 掃發票：第一次按會先下載掃描器（可能等幾秒），之後直接打開；沒有 Google Play 服務時會說明原因。
- [ ] 帳戶卡包：滾筒卡片間距較大、旁邊不變淡；慢慢放開停在最近一張，不會多轉；按完成後整疊依順序排（前面那張的下一個帳戶在它後面）。
- [ ] 總覽：結餘率在數字右邊同一行、眼睛在右上角；預算卡是「本月剩」＋十格；即將扣款寫「N 天後」與下一筆，字都不換行。
- [ ] 紀錄頁：主卡右上沒有筆數；在頁面上左右滑會換月份（在一筆紀錄上左滑仍是編輯／刪除）。
- [ ] 記一筆：切到投資再切回支出，下面沒有多出空白。

## 0.16.0　收支長條、滾筒卡包、紀錄卡

- [ ] 總覽、紀錄頁主卡：結餘下是一條綠紅長條，收入、支出（總覽還有中間的「其中股息」）寫在長條下；紀錄頁右上是「N 筆 · 轉帳 N」。
- [ ] 帳戶卡包：按住約半秒變成滾筒、輕震一下；上下拖時卡片明顯繞著轉，每經過一張輕震；放開順勢轉一下停在一張；按「完成」或點中間那張，它到最前面。
- [ ] 投資：主卡三欄同高；持股分「個股」「ETF」；股息頁選中的月份數字不超出黃底。
- [ ] 點紀錄列表的一筆：只看到這筆的卡（分類、名稱、金額，與有填的帳戶、日期、商家、標籤、分期、收據），按「編輯」才變表單。
- [ ] 總覽每日紀錄：週曆照舊，選中那天是主色；下面那天的紀錄是一排小卡，可左右滑，點一張打開。
- [ ] 記一筆：「掃發票」會打開掃描器；捲動時金額下沒有灰線；各頁標題下捲動時沒有灰線。
- [ ] 第一次打開投資頁，收盤價比之前快出來；帳戶主卡長條每段都看得到；新增帳戶的類型、圖示、幣別各在一塊灰底上；分類可選 100 種圖示。

## 0.15.0　一套色塊、3D 卡包、深色統一

- [ ] 各頁不再有白底加陰影的卡：總覽的預算、即將扣款、行情，信用卡頁、帳戶頁的小卡都是淡色塊加左上方形圖示；紀錄、帳戶、報表的清單是每組一塊淺灰底。
- [ ] 總覽、紀錄、帳戶頁、信用卡頁的主卡：大數字在上，收入、支出等是主卡裡並排的淡色小格；帳戶頁「比上月」的增減緊貼在淨資產數字右邊。
- [ ] 帳戶卡包：按住約半秒浮起，後面的卡都變成完整卡片、越後面越小並往後傾；往上或往下拖，每移一段固定距離換一張（每張輕震），不會一次跳好幾張；放手後回平。
- [ ] 深色模式逐頁看：沒有比帳戶卡更亮的色塊（財務分布、選中的日期、計算機的完成、開關打勾、持股頁的漲跌、通知頁的「試一則」都是深底淡色）。
- [ ] 有新版時的更新通知：點旁邊、按返回都不會關；「晚一點再說」今天不再跳，明天再出現；「略過這一版」之後這版不再跳，更新的版本才會。
- [ ] 記一筆：收據方塊與備註框上下對齊、一樣高；點收據跳出中間浮窗，有「拍照」「從相簿」兩個色塊；投資選標的頁的「新增」和標的卡一樣高。
- [ ] 定期交易圖示（更多、總覽的即將扣款）裡的循環箭頭完整，有箭頭尖。

## 0.14.1　整理程式與文件

這版不改功能，但字級統一到 11 級、按鈕改用同一套樣式，看起來可能略有不同。

- [ ] 各頁文字大小一致、沒有被截斷；原本 14 的字略大一點（15），不擠。
- [ ] 各頁按鈕（儲存、確定、入帳、恢復、設定預算等）在淺色是實心、深色是淡底加框；停用時是灰色。
- [ ] 設定 › 備份與還原：小螢幕、字放大時「沒有自動備份」與「匯出一份」「還原」都在一行內。
- [ ] 定期交易的「管理固定項目」「訂閱與固定支出」「已暫停」按返回會回到定期交易；排序帳戶、匯入照常開啟與關閉。

## 0.14.0　卡包、固定標題、深色統一

- [ ] 帳戶頁：按住卡包約半秒，卡包浮起並震一下；不放手往上或往下移，卡片一張一張轉到最前面（每換一張輕震）；放手後停在那張。點後面那張的卡頭也會把它換到前面；離開帳戶頁再回來仍是那張。
- [ ] 排序帳戶：最上面不再有說明文字；按住卡片任何地方約半秒，或一按右邊的 ≡，那張就放大浮起並震一下，可以拖。
- [ ] 各頁的標題（總覽、紀錄、帳戶、更多、設定、預算、定期、報表、投資、分類、標籤、代墊、信用卡、帳戶頁、持股頁）固定在上面，內容在下面捲動，捲動後標題下多一條細線；內容放得下的頁面（只差最下面的留白也算）拖不動，例如定期交易。
- [ ] 定期交易月曆：選中的那天外圍有一圈同色（沒有項目時是主色）的框，格子大小不變，一列一列對齊；沒有到期的那一週不留「到期」的空間；深色下有項目的日子是深底淡色，不是亮色塊。
- [ ] 預算管理沒設總預算時，主卡只有一行「本月花了 …」和右邊的「設定預算」。
- [ ] 深色模式：分類、設定、更多的方形圖示，投資的漲跌色塊、「今日」標籤，選中的小按鈕與面板的確定、儲存按鈕，都是深底加淡色字或外框，不再有發亮的色塊。
- [ ] 記一筆：打開再收起「商家、標籤、備註」或「拆分」，下面不留白；連續開關好幾次、關掉再打開都一樣。

## 0.13.0　備份與選擇器

- [ ] 備份與還原：不再有「Google 備份」卡；第一張是「Google 雲端硬碟」，打勾就是連結、取消就是解除連結；連結後顯示上次備份時間與「收據照片」開關。
- [ ] 最上面的主卡：雲端硬碟已連結或手機資料夾已設定時顯示上次備份時間；都沒有時是金色「沒有自動備份」。設定首頁的備份卡寫「雲端硬碟」「資料夾」。
- [ ] 換手機：新手機裝好 App，歡迎頁仍會問要不要從 Google 的系統備份還原（系統備份照常在背景寫，只是不再顯示）。
- [ ] 存到資料夾：打勾後先出現說明（選已有的資料夾，不能直接選「下載」或最外層），按「選資料夾」後選擇器直接開在「文件（Documents）」；選了不能用的位置時，會說明原因並可「重新選」；備份檔直接放在選的資料夾裡，沒有多一層。
- [ ] 選日期區間（紀錄的篩選選「自訂」、報表點期間、比較選自訂）：畫面中間的面板，上面有今天／本週／本月／上月／今年，下面是月曆，第一下點開始、第二下點結束，中間淡色連起來；淺色深色都協調。
- [ ] 每日記帳的提醒時間：畫面中間的面板，上面有 08:00、12:00、18:00、21:00、22:30，下面是時、分兩個滾輪，滾動時輕震。

- [ ] 預算管理：主卡與「每天可以花／月底預估」比以前小；分類／標籤額度維持方塊卡，但較小，一個畫面看得到更多。

- [ ] 全 App 的短標籤、按鈕字、卡片標題不會斷成兩行；放不下時字稍微縮小，再放不下才以「…」結尾。系統字放大到 130% 時也一樣。

- [ ] 帳戶頁：仍是疊在一起的卡包；點後面那張的卡頭，它滑到最前面、其他往上補（約 0.3 秒）；在最前面那張左右滑可換下一張；點最前面那張進入帳戶頁，長按開排序。
- [ ] 排序帳戶：按住右邊 ≡ 方塊的任何地方都能立刻拖（不用長按），拿起時卡片放大浮起並震一下、每換一格輕震；上方「手動／餘額／最近使用」可一鍵排好，排好後仍可再拖，按完成才存。
- [ ] 新增貸款：大色卡上直接打名字、點「借了多少」開計算機；年利率、期數、每月扣款三個色塊點了開中間面板，有常用數字可選；下方兩個色塊即時顯示每月繳與總利息；還款方式三個大色塊；從哪扣款、撥款到各是一個色塊；目前尚欠沒填就等於本金。
- [ ] 貸款頁的主卡多一行「本息平均 · 每月約 …」；舊的貸款沒有利率、期數時不顯示。
- [ ] 記一筆：打開「拆分」再關掉，下面不會多一塊空白；關掉記一筆再打開也一樣。

## 0.11.0　深色與質感

- [ ] 深色模式：總覽的圖表、分布條、分類色塊不比其他頁鮮豔刺眼；報表、標籤頁同樣柔和。
- [ ] 深色模式下選中的按鈕（報表分頁、投資持股／股息、標籤／商家、篩選類型、代墊與借貸、匯入匯出）是淡色底加同色外框與字，不是實心亮色塊；淺色模式不變。
- [ ] 卡片在深色下沒有陰影，以頁面底色、卡片、按鈕三階亮度分出層次。
- [ ] 震動回饋：記一筆讓預算超支時是較重的一下，平常存檔是輕的一下；拖曳帳戶排序、總覽區塊排序時每換一格輕震；切換開關時輕震。設定 › 外觀與操作 關掉「震動」後都不震。
