# 還原前安全副本的損壞回退

還原前的加密安全副本可能在寫入中斷後留下不完整檔案。鎖定狀態的唯讀匯出與已解鎖的「匯出還原前備份」，現在都由修改時間最新的副本開始，逐一檢查大小、解密認證與 V2 帳本快照；只有通過驗證的副本才會輸出。已解鎖路徑還會分別用本機密碼與救援文字解開同一副本。

最新檔案損壞時會嘗試較早的完整副本，因此輸出的資料**可能早於最近一次還原**。使用者應在乾淨的 V2 安裝環境核對內容後才決定是否還原。錯誤憑證或所有候選都損壞時拒絕匯出；這個流程不修改目前帳本、設定檔或任何副本。它不代表 App PIN、完整安全模式、Android 文件儲存實機或雲端驗證已完成。
