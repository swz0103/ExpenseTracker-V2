# V2 已驗證密碼後的帳本安全模式

V2 先驗證帳本密碼與設定檔，再檢查已發布的加密 Ledger。若 Ledger 目錄或目錄資料庫遺失、驗證失敗，App 將此結果視為**本機資料無法確認完整**，停止開啟財務工作階段並顯示安全模式。輸入錯誤密碼仍停留在一般解鎖畫面，不用錯誤密碼結果判定帳本損壞。

安全模式不自動新建空帳本、不覆寫損壞檔、不重設金鑰，也不提供交易寫入。若本機留有可驗證的還原前或升級前加密副本，畫面沿用唯讀匯出入口；匯出的副本可能早於目前資料，不能以它默默取代現有帳本。使用者應先保留目前 V2 資料與已保存的加密備份，再決定如何恢復。

這是登入時已發布 Ledger 的完整性阻擋。它沒有宣稱所有故障都可在 App 內修復；外部儲存、裝置金鑰或系統文件供應者失敗，仍須分別驗證。實機及雲端 gate 未通過前，不能將本子項當成完整 M1-07 安全模式驗收。
