# M1-05：交易搜尋

本批提供已解鎖帳本的唯讀搜尋。查詢直接讀取 Ledger 的有效事件與既有分類、標籤、商家及最新備註，不另存搜尋索引或修改交易；還原後以相同條件重新查詢即可得到還原版本的結果。刪除標記的交易不進入一般搜尋，歷史仍留在活動紀錄。

## 查詢契約

- `LedgerSearchQuery.version = 1`。日期起訖、任一受影響帳戶、分類、標籤、商家、事件種類、原幣、金額下限／上限及備註文字以 **AND** 組合；未提供的條件不限制結果。未知版本或欄位拒絕，舊 schema 不支援的條件也明確拒絕，不悄悄擴大結果。
- 日期與金額的上下限均包含端點。金額比較的是事件第一筆 leg 的**原幣本金絕對值**，使用者必須先指定幣別；轉帳手續費與收款本金不併入這個數字。這是搜尋條件，不是支出報表口徑；期初與轉帳也可被搜尋，但不能因此列為收入或消費。
- 帳戶條件符合事件涉及的任一帳戶，所以轉帳可由來源或目的帳戶找到。分類、標籤與商家保留當筆交易的穩定公開 ID；封存或更名不會使歷史交易消失。備註比對目前最新版本，ASCII 字母不分大小寫；不宣稱完整 Unicode 語言折疊。
- 以交易日及 ID 遞減排序，每頁最多 30 筆，使用穩定游標載入更多。每次查詢重新讀取已提交的資料；編輯條件後先清除舊結果，避免把上一組條件的結果誤標為新條件。

## 畫面與安全

首頁提供「搜尋交易」入口，包含日期、帳戶、分類、標籤、商家、種類、幣別、金額及備註條件；沒有相關 schema 能力的條件不顯示。結果沿用既有金額與備註遮罩，並可開啟交易活動。離開頁面或鎖定時銷毀查詢、結果與輸入文字；尚未完成的讀取受 session epoch 保護，不能在重新解鎖後顯示舊資料。

本批不宣稱完成 M1-05：月收支、分類／商家／帳戶基本報表及首頁消費彙總仍待後續實作與驗證。搜尋也不是匯出或帳本外索引。
