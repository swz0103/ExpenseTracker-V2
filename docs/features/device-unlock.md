# V2 本機裝置解鎖

帳本密碼和救援文字仍是開啟加密備份的正式憑證。本機裝置解鎖是使用者自行啟用的捷徑，不會寫入帳本、備份或同步資料，也不能取代救援文字。

使用者先以帳本密碼成功解鎖，勾選「在這台手機啟用裝置解鎖」，再通過 Android 的生物辨識或螢幕鎖。App 只在這個動作成功後，將帳本密碼副本保存於獨立命名空間的 Android Keystore 保護儲存區，且每次讀取都要求新的系統認證。畫面在系統認證期間隱藏財務內容。使用者可在帳本首頁停用；停用先撤銷捷徑標記，再刪除受保護的副本。重新安裝或換機仍需帳本密碼或救援備份。

裝置沒有符合條件的生物辨識或螢幕鎖、使用者取消認證、金鑰失效或裝置不支援時，捷徑失敗且帳本保持鎖定，仍可輸入帳本密碼。外部文件選取及真正離開 App（hidden／paused）仍立即鎖定；僅系統認證面板造成的短暫 inactive 不會中斷該次認證，而且必須回到前景才接受結果。Android 9 以下不啟用此捷徑；Android 10 以下是否能使用裝置 PIN 作為系統回退，取決於 Android 的認證能力，不能保證。

主機測試涵蓋明確啟用、背景鎖定、系統面板短暫失焦、認證取消、停用、離開 App 時拒絕延遲成功的認證結果，以及密碼回退。原生 Keystore 提示、不同 Android 版本、生物辨識變更、螢幕鎖移除與實機隱私仍待實機驗收。此功能也不等於獨立 App PIN；M1-07 的安全模式與整體安全 gate 仍未完成。

實作依賴固定版本的 [flutter_secure_storage 11.2.0](https://pub.dev/packages/flutter_secure_storage)；嚴格認證設定為 `enforceBiometrics: true`、`requireBiometricsPerOperation: true`，且禁止讀取錯誤時自動清除或演算法變更時無提示遷移。V2 維持獨立 Android App 身分及 `allowBackup=false`。
