# M1-05：月度收支與分類

月度收支以 Ledger 已提交交易的權威報表影響值重建，沒有另存一份可能過期的合計。查閱月份使用交易的民用日期；首頁預設手機當地曆法的目前月份，即使本月沒有收支也能開啟明細查看其他月份。尚未提供工作區時區設定或跨幣估值。本批對應 [RC-13 Reports](architecture-baseline-v1.0-rc1.md#rc-13) 的收支讀取子集；完整互動報表願景仍見 [FV-091](full-vision-baseline.md#fv-091)。

## 財務口徑

- 每個幣別獨立顯示收入、淨支出及兩者差額，不把不同幣別直接相加，也不以缺少的匯率推算基準幣總額。
- 期初餘額與轉帳本金不列收支；轉帳費用列支出。退款在退款發生月份沖減**原交易報表幣別**的支出，跨幣實收金額不會變成該月份另一幣別的收入。撤銷沿用原交易的反向報表影響，故單月收入或淨支出可以為負數。
- 一般列表已刪除標記的事件不進入月報；原始事件與標記仍保留於活動歷史。查詢後的每筆明細可前往既有活動紀錄。各筆金額使用既有隱私遮罩，鎖定後清空畫面狀態。
- 如果任何幣別合計或收支差額超出 Money 支援的整數範圍，整份月份報表拒絕顯示，帳本保持不變；不顯示截斷或部分數字。

## 讀取與邊界

`reports` 是只接受 Ledger 報表事實的純計算業務套件；Ledger session 依工作區、月份、有效事件讀取。報表不寫入 Ledger 或新增備份格式。加密備份還原後從還原事件重新計算；沒有待修復的衍生快取或過期標記。明細先顯示 30 筆並按需增加，總計仍涵蓋整個月份。

分類報表沿用同一批 Ledger 事件，單次讀取當月歷史分攤；每個分類依當時記錄的 ID 歸屬，不因日後改名、封存或合併而改寫。畫面使用目前名稱並標示封存／合併狀態。未分類的收支與轉帳費用列入獨立欄位，分類合計必須與該幣別月報一致。退款與撤銷沿用分攤的反向影響；分攤金額不等於事件原幣影響、重複分類或幣別不符時拒絕整份報表，不顯示部分統計。每個分類可展開其交易份額並前往活動歷史，遮罩與鎖定沿用月報行為。

[商家月報](merchant-reports.md)沿用相同收支事實，按歷史商家 ID 分組並保留未指定商家；[現金／銀行資產摘要](asset-summary.md)沿用已重建帳戶餘額。帳戶維度報表及整體 M1-05 gate 仍待後續，因此不宣稱 M1、雲端或實機 gate 已全部通過。
