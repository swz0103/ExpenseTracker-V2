# 版本紀錄

> 每個版本改了什麼，新的在上。實機驗收項目在 [acceptance.md](acceptance.md)。

## 0.17.0　背景收盤價、掃描器下載、卡包手感

- 收盤價與匯率：Android 背景每 3 小時先抓好存在手機，App 打開直接讀，過時才連網（`MarketWorker`、`CachedMarketTransport`）。
- 掃發票：不是從 Play 安裝的 App 第一次掃描時先下載 Google 掃描器，下載好自動開啟；問題直接寫出原因。
- 自動更新：每次開 App 都會真的查一次，不再沿用重開前的結果。
- 帳戶卡包：卡片拉開、不淡化；慢放停在最近一張，甩動最多三張；轉完整疊依滾筒順序排。
- 總覽：主卡結餘率靠右與數字同行、眼睛在右上；預算卡改成剩多少＋十格進度；即將扣款改成倒數「幾天後」與下一筆。
- 紀錄頁：主卡右上筆數拿掉；整頁左右滑切換月份。記一筆切換分頁不再留空白。

## 0.16.0　收支長條、滾筒卡包、紀錄卡

- 總覽與紀錄頁主卡：結餘下面一條收入對支出的長條和兩個數字，主卡裡不再有色塊。
- 帳戶卡包：按住變成直立滾筒，每張都是完整卡片，跟著手指轉、放開順勢轉一下再停在一張；按「完成」或點中間那張放到最前面。
- 投資主卡：市值與今日漲跌，下面三欄同高、細線分隔；成本移到「持股」旁。持股分「個股」「ETF」兩組，只顯示代號。
- 點開一筆紀錄：這筆紀錄自己的卡，只顯示有填的內容；每日紀錄改成可左右滑的小卡。
- 修正：掃發票沒反應、標題與記一筆捲動時的灰線、帳戶長條小金額看不到、代墊主卡對不齊、商家「其他」對不齊、報表分類圖塊字撞到、股息圖數字超出選中底。
- 收盤價所有股票同時抓、匯率一起抓；新增帳戶的選項各自分組；分類圖示 100 種。

## 0.15.0　一套色塊、3D 卡包、深色統一

- 白卡元件退場（[ADR-0006](adr/0006-retire-white-cards.md)）：小卡、主卡、清單分組、區塊標題、表單分組都換成色塊；主卡的收入、支出改成並排的淡色小格。
- 帳戶頁主卡的比上月增減移到淨資產數字旁；卡包按住浮起後每張都是完整卡片，往上下拖一格換一張。
- 深色：淡色塊、財務分布、選中的日期、計算機完成鍵、開關、漲跌膠囊都調到帳戶卡的深度。
- 更新通知只會被自己的按鈕關掉，新增「晚一點再說」（今天不再提醒）與「略過這一版」。
- 記一筆：收據方塊與備註框對齊，收據選單改成中間浮窗；選標的的「新增」與標的卡同高；定期交易圖示的箭頭重畫。
- 程式：帳本主檔拆出查詢與持股部分，不再依賴 Flutter 的繪圖（分類顏色存成整數）；測試改用 `Keys` 按按鈕；套件 README 統一格式；新增「頁面不用已退場元件」與「測試用 key」的規則測試。
- 測試帳本擴充成兩年、約 2,500 筆：多家銀行、三張信用卡（分期）、日圓與美元帳戶、車貸、代墊與借款、十檔股票（買賣、配息、配股）、預算與定期項目。

## 0.14.1　整理程式與文件（不改畫面）

- 程式分層重整：`core` 分成六部分、各功能的頁面回到自己的資料夾、功能之間不再互相需要；新增的規則都有測試守住。
- 設計系統：字級 `TextSize`、具名顏色、`solidButton`／`wordButton`；頁面不再寫死顏色、字級與按鈕樣式。
- 帳本依主題拆檔，貸款條件成為 `LoanTerms`；每個檔案 600 行以內。
- 網頁預覽看得到「備份與還原」；修正它在小螢幕、大字級時的溢出與換行。
- 文件改版：見 [docs/README.md](README.md)。

## 0.14.0　卡包、固定標題、深色統一

- 帳戶卡包按住浮起、上下轉動選出最前面那張；排序長按整張卡也能拖。
- 各頁標題固定，內容放得下時不能拖；定期月曆選中外框不再縮小格子。
- 深色下圖示、漲跌、選中按鈕改成深底淡色；修正記一筆收起摺疊後下方留白。

## 0.13.0　備份與選擇器
