# ADR-0007：收支主卡改成長條，紀錄改成自己的卡

- 狀態：採用（2026-11-15，作者決定），0.16.0 完成；取代 ADR-0006 中「主卡裡並排淡色小格」一項

## 背景

ADR-0006 把主卡的收入、支出、股息做成主卡裡的淡色小格。實機看起來是色塊疊色塊；點開一筆紀錄時，看到的仍是整張記一筆表單。

## 決策

| 項目 | 改成 |
| --- | --- |
| 總覽、紀錄頁主卡 | `BalanceHero`：結餘大字，下面一條收入對支出的長條，兩端寫數字；不放色塊 |
| 投資主卡 | 市值與今日漲跌，下面三欄同高、細線分隔 |
| 點開一筆紀錄 | 這筆紀錄自己的卡：分類色的卡寫種類、名稱、金額，其他有填的內容各一格；「編輯」才是表單 |
| 帳戶卡包 | 按住變成直立滾筒，跟著手指轉、有慣性、停在一張 |
| 每日紀錄 | 週曆不變；那天的紀錄是一排可左右滑的小卡 |
| 表單分組 | `FormGroup` 的選項放回淺灰底，讓類型、圖示、幣別分得開 |

## 後果

- `FigureCells` 只留在帳戶頁、信用卡頁的主卡。
- 預覽與選擇過程見 0.16.0 的 PR。
