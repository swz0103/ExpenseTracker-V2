# ADR-0004：設計系統只在 core/look，頁面只用名字

- 狀態：採用（2026-11-14）

## 背景

頁面裡寫了 391 個字級數字（12 種以上的大小）、49 個色碼、46 個各自設定的按鈕樣式。深色模式調整時漏掉好幾個按鈕與色塊，字級在不同頁面不一致。

## 決策

- 字級是 `TextSize` 的 11 個角色（[design.md](../design.md#字級)），原本的數字對到最接近的角色。
- 每個顏色在 `Hue`（或 `Palette`、`WidgetLook`）裡有名字；分類顏色是資料，可以出現在帳本、model 與範例帳本。
- 實心與文字按鈕的樣式由 `solidButton`、`wordButton` 產生，深色的處理只寫在那裡。
- `test/app/design_rules_test.dart`：`core/look` 以外不能寫色碼、字級數字、`styleFrom`。

## 後果

- 調整一個顏色或字級，所有頁面與兩種主題一起變。
- 原本 14 的字變成 15、32 的數字變成 34 等，畫面略有不同；版面測試全部通過，實機再確認一次（acceptance 0.14.1）。
- 新元件要先加進 `core/look`，頁面才能用。
