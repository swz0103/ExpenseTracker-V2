# ADR-0005：備份頁只給看得到、控制得了的方式

- 狀態：採用（2026-11-14，0.13.0）
- 補充：ADR-0001 §5

## 背景

備份頁原本有「Google 備份」卡：Android 系統自己的備份，使用者看不到檔案、也無法要它馬上送出，卡上的時間與開關造成誤解。另一方面，歡迎頁「換手機時從備份還原」正是靠這份系統備份帶過去的加密帳本（`files/cloud/`）。

## 決策

- 畫面上只留雲端硬碟與手機資料夾兩種自動備份，加上手動匯出與還原；主卡的「有自動備份」只看這兩種。
- 系統備份照常在背景寫（每次離開 App 且帳本有變），不再顯示、也不能關；以前關掉的人更新後會恢復。
- `allowBackup` 與只帶 `files/cloud/` 的規則不變（`backup_rules_test` 檢查）。

## 後果

- 換手機時仍能從歡迎頁還原；使用者不必理解系統備份的時機。
- 不想讓帳本進 Google 帳戶的人沒有開關可關；需要時再加回，放在「安全」而不是備份頁。
