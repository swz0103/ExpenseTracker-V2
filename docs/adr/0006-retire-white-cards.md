# ADR-0006：白卡元件退場，全 App 一套色塊

- 狀態：採用（2026-11-15，作者決定），0.15.0 完成

## 背景

0.9 之前的白卡元件（`Tile`、`TileRow`、`TileStats`、`SoftPanel`、`FormBlock`、`SectionHead`、`IconChip`、`IconBadge`）和之後的色塊元件（`HeroCard`、`ColorCard`、`SquareIcon`）並存：同一頁新舊風格混用，深色下白卡偏亮，區塊標題有三種寫法。

## 決策

| 項目 | 改成 |
| --- | --- |
| 小卡（總覽的預算、即將扣款、行情；帳戶與信用卡頁的小格；記一筆的帳戶、日期） | `ColorCard`：依內容顏色的淡底，左上實色方形圖示 |
| 頁面主卡（總覽本月結餘、帳戶頁餘額） | `HeroCard`，大數字在上；收入、支出、股息等改成主卡裡並排的淡色小格 |
| 紀錄清單（紀錄、帳戶、信用卡、每日紀錄、報表） | 拿掉白底大卡；每天一組淺灰淡底區塊，日期標題在外 |
| 區塊標題 | 只留一種：17 粗標題靠左，右邊可放小字或 › ；不加細線，靠間距分區 |
| 表單分組（新增帳戶的類型、圖示、幣別，信用卡的日期與額度） | 拿掉灰框，只留小標題，分組靠間距 |
| 小圖示 | 色塊與卡片的主圖示用方形實色（`SquareIcon`）；清單列與選單裡的用圓形淡底，兩種各有固定用途 |

深色下全部依帳戶卡的暗度（`tintOf`），不出現發亮的白卡或實心色塊。

## 後果

- 舊元件換完後刪除，`design_rules_test` 加上「頁面不用已退場的元件」。
- 與 2026-11-15 的實機回饋（[roadmap.md](../roadmap.md)）和其他待整理項目一起在 0.15.0 完成，只驗收一次。
- 不用的 `MenuPanel`、`MenuRow`、`PairBars` 直接刪除。
