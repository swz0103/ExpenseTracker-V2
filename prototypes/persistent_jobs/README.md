# M2-01：加密持久工作佇列（進行中）

這是雲端備份與後續提醒的佇列基礎，**尚未接上雲端服務，也未完成 M2-01**。目前只保存工作種類、冪等鍵、狀態與時間，不保存財務內容、備份檔、登入憑證或外部服務回應。資料庫以 V2 的 SQLCipher 機制加密；上層接入時須由安全儲存提供佇列專用金鑰。

同一冪等鍵重送只會得到原工作。工作領取有期限與隨機 token；程序中斷後可以重領，舊執行者不得確認新租約。失敗採有上限的指數退避；達上限後停止自動重試，需明確手動重排。工作種類含版本，例如 `backup.upload.v1`；執行者只領取支援的種類。外部服務仍可能收到多次請求，後續 adapter 必須以工作 ID 或備份物件 ID 實作冪等或確認結果。

這個獨立佇列**不能**用來聲稱 Ledger 提交後的副作用必達：需要和財務提交同生同死的工作，必須在 Ledger 的同一交易寫入 outbox。雲端備份只能上傳已產生、已驗證的加密封套；不可把簡易 JSON／CSV 交換檔當備份。後續還需接真實 provider、手動／自動排程、登入失效狀態、版本歷史、下載後乾淨還原，以及實機與雲端 gate。
