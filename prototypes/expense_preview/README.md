# 記帳 V2 開發 App

獨立 Android App ID：`dev.expensetracker.preview`，不覆蓋地基原型。只建置 debug ARM64 APK，正式 release variant 關閉。這是持續開發中的 M1 入口，完整 M1／M2／M3 尚未完成；可安裝不作為停止點。

> 2026-10-01 狀態提示：下方「已接入」保留早期逐批開發紀錄，其中 schema 15 與「信用卡／投資保留後續」等句子已不是目前狀態。正式 App 現為 schema 24，信用卡、投資、provider-neutral 雲端備份 runtime、免帳號日終／參考匯率及到價提醒均已形成可操作垂直切片。請以[功能完成矩陣](../../docs/capability-matrix.md)與[最新工作進度](../../docs/work-progress.md)為目前事實；真實雲端 OAuth、合規分鐘行情來源、OS 背景輪詢及實機仍未完成。

## 已接入

- 簡易收入／支出 JSON／CSV 匯入：從 Android 系統選取檔案，必要時重新解鎖，逐一對應帳戶、審閱逐幣別金額及確認後整批寫入；相同來源重試不重複入帳。同一本帳的匯出檔不可再匯入自身。主機 4,999 筆新增與第 5,000 筆超額原子拒絕已驗；實機仍待測。[範圍](../../docs/features/simple-import-ledger.md)。
- 簡易收入／支出 JSON／CSV 匯出：Android 選儲存位置後需重新解鎖、檢查納入及略過筆數，並再次確認。檔案未加密，只包含普通收支的日期、金額、帳戶識別及最新備註；分類、標籤、商家、期初及複雜交易等不包含。它不能取代完整加密備份，實機保存仍待測。[範圍](../../docs/features/simple-import-ledger.md)。
- 月預算：以 schema 15 加密保存版本歷史，依已生效帳本計算同幣別已用／剩餘與提醒；簡潔畫面可新增、修改及確認刪除。舊 V2 帳本需要明確「備份並更新」，不能自動改寫；主機回歸已通過，實機及本批雲端 gate 待驗。[進度](../../docs/work-progress.md)。

- 首次設定至少 12 字元密碼、另存救援文字確認、空帳本；重新啟動與背景鎖定。操作層拒絕未解鎖命令，已接受的交易可完成，重新解鎖核對結果；重試沿用 operation ID。
- 現金／銀行帳戶、期初餘額、TWD／USD（2 位）及 JPY（0 位）、收入／支出、日期、餘額及每頁 30 筆交易。金額不使用浮點數；不同幣別不直接加總。
- 使用 Android 系統檔案選擇器匯出加密備份；寫入後重新讀回比對，取消不表示已儲存。選擇器導致離開前景時仍鎖定，返回需解鎖。
- 密碼或救援文字匯入；先保存並雙路驗證現有帳本的加密副本，再透過世代發布切換。可匯出最近一次還原前副本。原世代／key 保留。

- 雙層收入／支出分類：新增、改名、搬移、封存／啟用、明確合併，收支錄入及歷史引用。
- 平面 Tag：新增、改名、封存／啟用、明確合併；每筆收支最多 16 個選取，與金額／分類一起原子提交，歷史保留原 ID 與版本。
- 商家：新增、改名、封存／啟用、明確合併與別名增刪；每筆收支可選一個商家，候選需手動確認，保留歷史引用。
- 新帳本 schema 15；既有 V2 schema 3～14 經明確確認、雙憑證安全備份及逐步暫存驗證後升級。此流程不讀取或搬入舊版 App 資料。

- 日常收入／支出可「再記一筆類似交易」：只沿用可用帳戶、分類、標籤、商家及幣別，金額日期重新輸入；封存或合併項目需重新選擇。

- 期初／收支共用繁體中文月曆與手動日期欄位：確認才套用，部分文字可保存草稿，背景鎖定取消；範圍與 BusinessDate 相同。操作錯誤回到可見提示，保留已填欄位。
- 日期及金額計算器的文案使用 Flutter gen-l10n／ARB；目前固定繁體中文，其他畫面文字尚未全部集中，不宣稱多語系完成。修改 lib/l10n/*.arb 後執行 flutter gen-l10n。

- [同幣轉帳](../../docs/features/same-currency-transfers.md)：明確選擇雙方帳戶、來源手續費、可恢復加密草稿與凍結送出；列表分開本金／費用／來源合計，沿用隱私遮罩。
- [跨幣轉帳](../../docs/features/cross-currency-transfers.md)：保存兩邊實際本金與來源費用，以精確比例標記實際金額依據；專用草稿格式與 schema 9／snapshot 8／8 → 9 安全升級防止舊 reader 誤讀。主機驗證狀態見工作進度，實機未驗證。

- [多分類拆分](../../docs/features/split-entry-drafts.md)：每筆收支 2～16 項正額分類、精確合計、可恢復草稿、凍結重試及遮罩明細；複製時重新填寫所有金額。沿用 schema 9／snapshot 8。

- [部分／全額退款](../../docs/features/refunds.md)：追溯原支出／分類、原幣退款上限與實收金額，保存草稿、凍結重試及歷史歸屬；schema 10／snapshot 9 開始支援。
- [完整撤銷](../../docs/features/financial-reversals.md)：收入、支出及轉帳逐項反向，含原手續費；保留原交易與唯一關聯、原因、確認及可恢復草稿。已有退款或撤銷的來源互斥拒絕。schema 11／snapshot 10 與 10 → 11 安全升級已接入。
- [活動查閱](../../docs/features/transaction-activity.md)：原交易、退款及撤銷的同一家族、記錄時間分頁與隱私遮罩；一般 revision 歷史待後續。

## 備份憑證與本機設定

每次安裝有自己的加密 profile，內含本機控制身份、初始 workspace、可重試初始化 operation。救援文字在平台安全儲存，啟動時須能同時解開 profile 並核對；缺失或損毀時不自行替換。解鎖密碼只在已解鎖期間留於記憶體；Dart／平台記憶體不宣稱可可靠歸零。

完整 `profile.pending` 在密碼／救援 key 核對且空帳本已驗證發布後，才完成設定。已發布設定卻找不到 catalog／active generation 時停止，不重建空帳本；未知或不完整設定不自動清除。每個 App 組合根只建立一個 engine；尚未設計多 App instance 同時初始化設定。

匯入時，輸入的是來源備份憑證；後續匯出使用本次安裝已明確設定的密碼與救援文字。還原畫面會先說明此差異。救援文字能解開已有備份，不等於找回未備份資料，也不能直接重設本機解鎖密碼。正式多 workspace BackupProfile／排程備份與密碼輪替仍未完成。

## 容量與範圍

目前接口限制 32 帳戶、5,000 交易（包含期初）、256 分類／1,024 次分類異動、256 Tag／1,024 次 Tag 異動、256 商家／1,024 次商家異動；總計仍限制 50,000 列／16 MiB。匯入僅接受可完整處理的單 workspace、期初／收入／支出／同幣與跨幣轉帳／退款／完整撤銷及分類／Tag／商家與別名歷史。完整財務與歷史引用驗證在加密 stage 執行，未知格式不降級開啟。不同大量資料實驗不可相加當成單一帳本容量。

一般 revision、財務更正替代、tombstone、外部 FX 行情、搜尋／報表、信用卡及投資保留後續開發。舊世代與安全副本尚無自動清理介面；重複還原會增加私人儲存使用量。M3 的 100k+ 目標尚未達成，不以目前容量限制取代該門檻。

## 驗證分級

Host 整合使用真實 SQLCipher 和測試用記憶體 vault；widget 測試使用同一 engine，核對小螢幕完整輸入及背景鎖定。Android secure storage／檔案選擇器在本輪只做編譯及封裝檢查，沒有新增實機證據；舊地基裝置測試不能冒充此 App 已實測。依使用者最新指示，不呼叫 adb、不安裝或操作手機。
