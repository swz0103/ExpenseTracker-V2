# 記帳 V2 最小試用版

獨立 Android App ID：`dev.expensetracker.preview`，不覆蓋地基原型。只建置 debug ARM64 APK，正式 release variant 關閉。這是可輸入資料的 M1 最小試用入口，完整 M1／M2／M3 尚未完成。

## 已接入

- 首次設定至少 12 字元密碼、另存救援文字確認、空帳本；重新啟動與背景鎖定。操作層拒絕未解鎖命令，已接受的交易可完成，重新解鎖核對結果；重試沿用 operation ID。
- 現金／銀行帳戶、期初餘額、TWD／USD（2 位）及 JPY（0 位）、收入／支出、日期、餘額及每頁 30 筆交易。金額不使用浮點數；不同幣別不直接加總。
- 使用 Android 系統檔案選擇器匯出加密備份；寫入後重新讀回比對，取消不表示已儲存。選擇器導致離開前景時仍鎖定，返回需解鎖。
- 密碼或救援文字匯入；先保存並雙路驗證現有帳本的加密副本，再透過世代發布切換。可匯出最近一次還原前副本。原世代／key 保留。

## 備份憑證與本機設定

每次安裝有自己的加密 profile，內含本機控制身份、初始 workspace、可重試初始化 operation。救援文字在平台安全儲存，啟動時須能同時解開 profile 並核對；缺失或損毀時不自行替換。解鎖密碼只在已解鎖期間留於記憶體；Dart／平台記憶體不宣稱可可靠歸零。

完整 `profile.pending` 在密碼／救援 key 核對且空帳本已驗證發布後，才完成設定。已發布設定卻找不到 catalog／active generation 時停止，不重建空帳本；未知或不完整設定不自動清除。每個 App 組合根只建立一個 engine；尚未設計多 App instance 同時初始化設定。

匯入時，輸入的是來源備份憑證；後續匯出使用本次安裝已明確設定的密碼與救援文字。還原畫面會先說明此差異。救援文字能解開已有備份，不等於找回未備份資料，也不能直接重設本機解鎖密碼。正式多 workspace BackupProfile／排程備份與密碼輪替仍未完成。

## 容量與範圍

試用接口限制 32 帳戶、5,000 交易（包含期初）；容量與 110,011 次財務操作證據見[測試報告](../../docs/preview-validation-report.md)。匯入僅接受可完整顯示的單 workspace、期初／收入／支出、每筆一個 leg／receipt／audit，不接受進階封存歷史、分類或轉帳。完整財務驗證仍在加密 stage 執行，未知格式不降級開啟。

分類／商家／標籤、修改刪除、退款、轉帳、FX、報表、信用卡及投資保留後續開發。舊世代與安全副本尚無自動清理介面；重複還原會增加私人儲存使用量。

## 驗證分級

Host 整合使用真實 SQLCipher 和測試用記憶體 vault；widget 測試使用同一 engine，核對小螢幕完整輸入及背景鎖定。Android secure storage／檔案選擇器在本輪只做編譯及封裝檢查，沒有新增實機證據；舊地基裝置測試不能冒充此 App 已實測。依使用者最新指示，不呼叫 adb、不安裝或操作手機。

## 本輪驗證狀態

最終 App 19 項 engine／widget、本輪受影響套件共 131 項本機回歸通過。兩輪合計 55,000 筆新增交易／55,011 次重送驗證通過，資料量、時間及限制見[完整報告](../../docs/preview-validation-report.md)；APK 與操作步驟見[安裝驗收](../../docs/installable-preview.md)。本輪未操作手機。
