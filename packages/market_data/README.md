# Market data adapters

This package is an Android/desktop-ready provider layer. It has no UI, persistence, background job or Ledger posting side effects. `MarketDataGateway.stockClose` accepts a market-qualified `InvestmentInstrument`; `fxRate` accepts exact `Currency` values. A caller must show the returned state, source, observation date and retrieval time, and must never use a stale or missing result as a current valuation. User-confirmed broker and bank amounts remain authoritative for transactions.

## Supported routes

- `TWSE` / `TWD` / numeric 4-digit stocks or `00`-prefixed 4–6 digit ETFs: latest **daily closing traded price** from [TWSE STOCK_DAY_ALL](https://openapi.twse.com.tw/), with the ROC observation date parsed from the returned row. The [government dataset](https://data.gov.tw/dataset/11549) is daily and licensed under the [Open Government Data License v1](https://data.gov.tw/license). An App displaying this data must include the license's provider attribution. The feed is a latest snapshot, so this method does not claim historical, intraday, OTC, US-market or corporate-action coverage. The caller owns instrument classification; a matching code alone is not proof of a valid stock/ETF identity.
- `EUR/USD`, `EUR/JPY`, `EUR/GBP`, `EUR/CHF` and their exact inverses: [ECB EXR daily reference rates](https://data.ecb.europa.eu/help/api/data-examples). The ECB series is EUR-base; inverse results are marked `derivedInverse`. Exact-date queries use `startPeriod` and `endPeriod` and return `missing` if that day has no observation. Other pairs, including `USD/TWD`, are explicitly `unsupported`. These are [informational reference rates, not transaction rates](https://www.ecb.europa.eu/stats/policy_and_exchange_rates/euro_reference_exchange_rates/html/index.en.html). [ECB terms](https://www.ecb.europa.eu/services/using-our-site/disclaimer/html/index.en.html) require accurate source attribution and disclosure of modifications such as inversion.

The default transport uses HTTPS with a 10-second connection/response timeout, no redirects, and a 2 MiB body limit. The in-memory cache keeps at most 32 endpoint responses for 20 minutes. Requests are coalesced per URI, and each provider host has a 10-second request cooldown; a cached observation is returned as `stale` if refresh fails or is throttled. Observation dates more than four calendar days old are `stale` by default. These are configurable caller policies, not claims about exchange or central-bank publication schedules. No key or account is required.

Provider rows are parsed from decimal text, without `double`; prices remain decimal text and FX uses `FxRate`'s exact rational value. `available`, `stale`, `missing`, `unsupported`, `failed` and `throttled` are distinct results. Missing values never become zero or 1:1. The package's tests use deterministic provider fixtures and do not assert live uptime. A real device/network smoke test and App route integration still remain.

Run `dart pub get --offline`, `dart analyze` and `dart test` from this directory after dependencies are available locally.
