# Market data adapters

This package is an Android/desktop-ready provider layer. It has no UI, persistence, background job or Ledger posting side effects. `MarketDataGateway.stockClose` accepts a market-qualified `InvestmentInstrument`; `fxRate` accepts exact `Currency` values. A caller must show the returned state, source, observation date and retrieval time, and must never use a stale or missing result as a current valuation. User-confirmed broker and bank amounts remain authoritative for transactions.

`MarketProviderRegistry` accepts any number of independently identified adapters. `MarketDataRouter` supports automatic priority, a fixed provider that never silently switches, explicit fallback attempts, and cross-checking without averaging. Every routed attempt retains provider ID, dataset, attribution, state and reason; the selected provider remains visible. TWSE, TPEx, ECB and CBC datasets are exposed as independent adapters; future intraday, US-market or authorized commercial adapters can register without changing router logic.

## Supported routes

- `TWSE` / `TWD` / numeric 4-digit stocks or `00`-prefixed 4–6 digit ETFs: latest **daily closing traded price** from [TWSE STOCK_DAY_ALL](https://openapi.twse.com.tw/), with the ROC observation date parsed from the returned row. The [government dataset](https://data.gov.tw/dataset/11549) is daily and licensed under the [Open Government Data License v1](https://data.gov.tw/license). An App displaying this data must include the license's provider attribution. The feed is a latest snapshot, so this method does not claim historical, intraday, OTC, US-market or corporate-action coverage. The caller owns instrument classification; a matching code alone is not proof of a valid stock/ETF identity.
- `TPEX` / `TWD` / the same deliberately narrow stock or ETF symbol shapes: latest **daily closing traded price** from [TPEx `tpex_mainboard_daily_close_quotes`](https://www.tpex.org.tw/openapi/). The [government dataset](https://data.gov.tw/dataset/11370) is daily, free and uses the Open Government Data License v1. It is a latest snapshot, not intraday data or an arbitrary historical-date API. Other security types present in the source are not accepted merely because a row exists.
- `EUR/USD`, `EUR/JPY`, `EUR/GBP`, `EUR/CHF` and their exact inverses: [ECB EXR daily reference rates](https://data.ecb.europa.eu/help/api/data-examples). The ECB series is EUR-base; inverse results are marked `derivedInverse`. `fxRate(requiredAsOf: ...)` queries one exact date and returns `missing` if it has no observation. `historicalFxRate(date: ..., lookbackDays: ...)` queries the official date range, selects the latest actual observation within at most seven preceding calendar days, and marks a preceding date `stale`. It never labels a Friday quote as a Sunday quote. Other pairs, including `USD/TWD`, are explicitly `unsupported`. These are [informational reference rates, not transaction rates](https://www.ecb.europa.eu/stats/policy_and_exchange_rates/euro_reference_exchange_rates/html/index.en.html). [ECB terms](https://www.ecb.europa.eu/services/using-our-site/disclaimer/html/index.en.html) require accurate source attribution and disclosure of modifications such as inversion.
- `USD/TWD` and its exact inverse: the [CBC daily interbank close dataset](https://data.gov.tw/dataset/7232). The published value is TWD per USD and inversion is disclosed. An exact requested business date returns `missing` when absent; historical lookup may select an actual prior observation within a caller-bounded seven-day window and marks it `stale`. The value is a reference observation sourced by CBC from Taipei Forex Inc., not the user's bank transaction rate.

## Intraday routes

`FugleIntradayStockProvider` adds authenticated TWSE/TPEx TWD stock and ETF bars from Fugle's [intraday candles endpoint](https://developer.fugle.tw/docs/data/http-api/intraday/candles/). One-minute and five-minute bars are separate query capabilities. The adapter obtains an API key from a caller-supplied asynchronous source for each network attempt; it does not persist, log or embed the key. The HTTP transport sends the key only to the pinned HTTPS `api.fugle.tw` host and refuses redirects.

Every result retains the bar start time and fetch time. The adapter selects the greatest actual timestamp rather than trusting response order, validates symbol/market/interval, positive decimal OHLC, OHLC range, integral volume, duplicate/future timestamps, body size and status semantics. A one-minute bar older than two minutes or a five-minute bar older than six minutes is `stale`, never current. `401`/`403`, `404` and `429` remain authorization failure, missing data and throttling respectively. The registry marks this provider as requiring authorization and can route additional intraday providers later.

Fugle's current [personal pricing page](https://developer.fugle.tw/docs/pricing/) says the registered basic tier supports 60 intraday calls/minute and five WebSocket subscriptions; paid tiers raise those limits. These terms can change and do not by themselves grant redistribution or commercial App rights. This repository has deterministic fixtures only: no account was created and no live key was used. Official TWSE/TPEx daily closes remain independent end-of-day baselines, not a false intraday fallback.

`IntradayRefreshController` turns a provider lookup into a lifecycle-owned update stream. The caller chooses a refresh interval from one through five minutes. Start performs an immediate request; scheduled and manual refreshes never overlap. Stop cancels the pending timer and ignores late results, while a rapid stop/start safely resumes after an older in-flight request settles. Failed or throttled attempts use bounded exponential backoff (15 minutes by default), then a successful/non-transient result resets the normal cadence. The controller does not run an Android background service by itself; a screen or app lifecycle owner must start, stop and dispose it.

The default transport uses HTTPS with a 10-second connection/response timeout, no redirects, and an 8 MiB body limit (the official TPEx snapshot is larger than 2 MiB). The in-memory cache keeps at most 32 endpoint responses for 20 minutes. Requests are coalesced per URI, and each provider host has a 10-second request cooldown; a cached observation is returned as `stale` if refresh fails or is throttled. Observation dates more than four calendar days old are `stale` by default. These are configurable caller policies, not claims about exchange or central-bank publication schedules. These four daily/reference providers require no key or account.

Provider rows are parsed from decimal text, without `double`; prices remain decimal text and FX uses `FxRate`'s exact rational value. `available`, `stale`, `missing`, `unsupported`, `failed` and `throttled` are distinct results. Missing values never become zero or 1:1. The package's tests use deterministic provider fixtures and do not assert live uptime. A real device/network smoke test and App route integration still remain.

Run `dart pub get --offline`, `dart analyze` and `dart test` from this directory after dependencies are available locally.
