# 定期交易候選規則

這是 M2-03 的第一個業務子項，僅計算固定金額交易的到期候選，不直接寫入 Ledger，也不發通知。使用者仍須逐筆確認入帳。

- 支援每日、每週、每月、每年及每 N 期。月末與閏日都以原始起始日為錨點；短月暫時夾到當月最後一天，下個月重新使用原始日。
- `after` 為不含、`through` 為含；離線後可以一次找回區間內候選。每筆候選有由模板 ID、版本及到期日構成的穩定重試鍵。
- 超過候選上限時明確失敗，不默默漏掉交易。此上限不是已入帳去重機制。
- 模板權威保存、審閱與確認 UI、通知、已確認紀錄、加密備份還原及實機驗證尚未實作，因此 M2-03 仍在進行中。
