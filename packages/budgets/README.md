# Budgets（M2-02 業務規則進行中）

2026-09-29：實際加密 Ledger 的有效月報與歷史標籤參照已接到 App 預算計算入口。版本化計畫現保存於 schema 15 加密帳本，納入可攜快照及雙憑證還原；現有 V2 帳本透過明確確認的安全升級，App 提供簡潔的設定、已用／剩餘與警示。主機驗證包含取消、錯誤輸入與重試、升級中斷及完整 App／Ledger 回歸，詳見進度。實機與此批雲端 gate 未完成，M2-02 維持進行中。

本套件用 Ledger 已分類的月報效果計算單月支出預算，不重新解讀交易腿。轉帳本金與期初為零；手續費計入支出；退款與反向事件依原月報效果扣回。計算使用整數最小貨幣單位，溢位直接拒絕。

預算指定工作空間、月份、幣別與正數上限，可選雙層分類、帳戶、標籤及警示百分比。帳戶與標籤各自的多個選項為「任一」，兩者和分類為「全部符合」；選父分類涵蓋其子分類。拆分交易只計符合分類的份額。不同幣別不猜測匯率，結果回報略過的筆數，畫面須揭露。分類依已保存的分類 ID 判斷，後續合併或改名不得靜默改寫歷史交易歸屬。若預算條件重疊，不能把多個預算已用金額直接相加當作總支出。

計畫編碼包含工作空間、月份、幣別／最小單位、分類、帳戶、標籤、警示百分比及修訂版本；未知欄位、未來格式、重複篩選與超額資料拒絕。schema 15 以追加修訂保存，操作 ID 防止重送重複寫入，刪除留下歷史 tombstone；完整加密備份含權威版本歷史。畫面目前提供單一帳戶／標籤篩選，底層可處理多選；具多選的既有計畫在簡易畫面只讀，避免改寫時遺失條件。預算互相重疊時，畫面逐筆顯示，**不能加總各筆已用金額**。實機及此批雲端 gate 未完成；M2-01 真實雲端備份亦尚未通過。
