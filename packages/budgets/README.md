# Budgets（M2-02 業務規則進行中）

2026-09-29：已把實際加密 Ledger 的有效月報與歷史標籤參照接到 App 預算唯讀計算入口。標籤由單一月報查詢擷取，不以目前標籤名稱重算，退款與已排除的軟刪除沿用月報口徑。整合測試涵蓋分類、標籤、退款及重新開啟帳本。預算設定持久保存、migration、設定與閱讀 UI、加密備份還原及實機 gate 仍未完成，M2-02 維持進行中。

本套件用 Ledger 已分類的月報效果計算單月支出預算，不重新解讀交易腿。轉帳本金與期初為零；手續費計入支出；退款與反向事件依原月報效果扣回。計算使用整數最小貨幣單位，溢位直接拒絕。

預算指定工作空間、月份、幣別與正數上限，可選雙層分類、帳戶、標籤及警示百分比。帳戶與標籤各自的多個選項為「任一」，兩者和分類為「全部符合」；選父分類涵蓋其子分類。拆分交易只計符合分類的份額。不同幣別不猜測匯率，結果回報略過的筆數，畫面須揭露。分類依已保存的分類 ID 判斷，後續合併或改名不得靜默改寫歷史交易歸屬。若預算條件重疊，不能把多個預算已用金額直接相加當作總支出。

目前有可測的計算規則與 App 唯讀查詢入口。尚缺同一工作空間內的版本化保存／migration、使用者設定與閱讀畫面、加密備份還原及實機 gate；因此 M2-02 仍在進行中。M2-01 真實雲端備份也尚未通過，不以本套件宣稱 M2 驗收。
